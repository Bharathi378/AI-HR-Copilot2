# AI HR Copilot

## Overview
AI HR Copilot is an AI-powered resume screening and candidate ranking system developed using Python and Streamlit. It helps recruiters compare resumes with a job description and automatically ranks candidates.

## Features
- Resume Screening
- Candidate Ranking
- AI Match Score
- Skill Gap Analysis
- HR Recommendation (Recommend / Consider / Reject)
- PDF Report Generation

## Technologies Used
- Python
- Streamlit
- Sentence Transformers
- Scikit-learn
- Pandas
- PyMuPDF (fitz)

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Run the application

streamlit run app.py
